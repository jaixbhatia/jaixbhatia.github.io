# Media Folder for CS180 Project 1

This folder stores images, screenshots, diagrams, and other media related to Project 1.

## Supported File Types
- Images: .jpg, .jpeg, .png, .gif, .svg
- Documents: .pdf (for diagrams or reports)
- Videos: .mp4, .webm (if applicable)

## Recommended Naming Convention
- `screenshot1.jpg` - Main project screenshot
- `diagram.png` - Architecture or flow diagram
- `result.jpg` - Final output or demonstration
- `code-snippet.png` - Important code sections

## How to Use
1. Add your media files to this folder
2. Update the `cs180/1/index.html` file to reference your actual images
3. Replace the placeholder text with real content

## Example HTML Usage
```html
<img src="media/screenshot1.jpg" alt="Project Screenshot">
```

## File Size Guidelines
- Keep images under 2MB for optimal loading
- Use appropriate compression for web display
- Consider using responsive images for different screen sizes
